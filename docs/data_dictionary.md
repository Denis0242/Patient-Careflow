# Data Dictionary

| Field | Description |
|---|---|
| Patient ID | Unique patient identifier |
| Event | Patient journey event |
| Journey Date | Date of patient journey activity |
| Funnel Stage | Care journey stage |
| Funnel Stage Order | Numeric order of funnel stage |
| Age Group | Patient age segment |
| Condition | Patient condition category |
| Visit Type | Telehealth, hybrid, or in-person visit type |
| Region | Patient region |
| Patient Risk Category | Risk segmentation for patient follow-up |
| D1 Retained | 1 if patient retained on day 1, else 0 |
| D7 Retained | 1 if patient retained on day 7, else 0 |
| D30 Retained | 1 if patient retained on day 30, else 0 |
| Treatment Completed | 1 if patient completed treatment, else 0 |
| Follow-up Completed | 1 if follow-up was completed, else 0 |
| Outcome Success | 1 if outcome was successful, else 0 |
| Engagement Score | Patient engagement score |
| Treatment Cost | Treatment cost amount |
